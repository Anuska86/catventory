# Catventory

### Core Technologies
- **React 19.2.0**
- **Bootstrap 5.3.7**
- **Redux Toolkit**
- **React Router v7**
- **Sass/SCSS**

**Install Dependencies**
   ```bash
   npm install --legacy-peer-deps
   ```

**Start Development Server**
   ```bash
   npm start
   ```
   
   The application will open in your browser at `http://localhost:3001`
